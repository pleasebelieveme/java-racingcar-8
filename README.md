## ⚙️ 기능 구현 목록

### 1. 도메인 객체 구현

#### 1.1 Car 객체 구현
- [ ] 자동차 이름을 저장한다
- [ ] 자동차의 현재 위치를 저장한다
- [ ] 전진 메서드를 구현한다 (위치 +1)
- [ ] 현재 위치를 반환하는 메서드를 구현한다
- **커밋:** `feat(domain): Car 객체 기본 기능 구현`
- **테스트:** `test(domain): Car 객체 생성 및 전진 테스트`

#### 1.2 Cars 객체 구현 (여러 자동차 관리)
- [ ] 여러 Car 객체를 관리한다
- [ ] 모든 자동차를 한 번씩 이동시키는 메서드 구현
- [ ] 우승자(최대 위치)를 찾는 메서드 구현
- **커밋:** `feat(domain): Cars 객체 구현`
- **테스트:** `test(domain): 우승자 판별 테스트`

### 2. 입력 검증 구현

#### 2.1 자동차 이름 길이 검증
- [ ] 이름이 5자를 초과하면 `IllegalArgumentException` 발생
- **커밋:** `feat(validator): 자동차 이름 길이 검증 구현`
- **테스트:** `test(validator): 이름 길이 검증 테스트`

#### 2.2 자동차 이름 유효성 검증
- [ ] 이름이 비어있으면 예외 발생
- [ ] 중복된 이름이 있으면 예외 발생
- **커밋:** `feat(validator): 이름 빈 값 및 중복 검증 구현`
- **테스트:** `test(validator): 이름 중복 검증 테스트`

#### 2.3 이동 횟수 검증
- [ ] 이동 횟수가 0 이하이면 예외 발생
- [ ] 숫자가 아니면 예외 발생
- **커밋:** `feat(validator): 이동 횟수 검증 구현`
- **테스트:** `test(validator): 이동 횟수 검증 테스트`

---

### 3. 랜덤 기반 전진 로직

#### 3.1 무작위 값 생성 및 전진 조건
- [ ] 0~9 사이의 무작위 값 생성 (`Randoms.pickNumberInRange()`)
- [ ] 값이 4 이상이면 true, 미만이면 false 반환
- **커밋:** `feat(util): 전진 조건 판별 유틸 구현`
- **테스트:** `test(util): 전진 조건 테스트` (Mock 또는 고정값 테스트)

### 4. 입출력 기능

#### 4.1 자동차 이름 입력
- [ ] 사용자에게 자동차 이름 입력 안내 메시지 출력
- [ ] `,` 기준으로 이름을 분리하여 리스트로 반환
- **커밋:** `feat(view): 자동차 이름 입력 기능 구현`

#### 4.2 이동 횟수 입력
- [ ] 사용자에게 이동 횟수 입력 안내 메시지 출력
- [ ] 입력값을 정수로 변환하여 반환
- **커밋:** `feat(view): 이동 횟수 입력 기능 구현`

#### 4.3 자동차 이동 상태 출력
- [ ] 각 자동차의 이름과 위치를 출력 (`이름 : ---`)
- [ ] 매 라운드마다 모든 자동차 상태 출력
- **커밋:** `feat(view): 이동 상태 출력 기능 구현`

#### 4.4 우승자 출력
- [ ] 우승자 이름을 출력 (`최종 우승자 : pobi`)
- [ ] 공동 우승자는 `,`로 구분 (`pobi, jun`)
- **커밋:** `feat(view): 우승자 출력 기능 구현`

## 📋 패키지 구조

| 패키지 | 클래스 | 책임 |
|--------|--------|------|
| `domain` | Car | 자동차의 상태(이름, 위치) 관리 |
| | Cars | 여러 자동차 관리, 우승자 판별 |
| `service` | RacingGameService | 게임 전체 흐름 조율 |
| `view` | InputView | 사용자 입력 처리 |
| | OutputView | 게임 결과 출력 |
| `validator` | InputValidator | 입력값 검증 및 예외 처리 |
| `util` | RandomGenerator | 랜덤값 생성 및 전진 조건 판별 |
```
com.racingcar
 ├─ Application.java           // main() 진입점
 │
 ├─ domain                      // 핵심 비즈니스 로직
 │    ├─ Car.java
 │    └─ RacingGame.java
 │
 ├─ service                     // 게임 진행 조율
 │    └─ RacingGameService.java
 │
 ├─ view                        // 입출력 처리
 │    ├─ InputView.java
 │    └─ OutputView.java
 │
 ├─ validator                   // 입력 검증
 │    └─ InputValidator.java
 │
 └─ util                        // 순수 유틸리티
      └─ RandomGenerator.java
```

## 🚀 개발 진행 순서

본 프로젝트는 **Inside-Out 방식**으로 진행합니다.

### 개발 전략
1. **도메인 우선**: 핵심 비즈니스 로직을 먼저 구현하고 테스트
2. **의존성 최소화**: 외부 라이브러리(Console 등)에 의존하지 않는 코드부터 작성
3. **점진적 통합**: 작은 단위를 완성한 후 조합

### 순서
```
Domain (순수 객체)
  ↓
Validator (검증 로직)
  ↓
Util (헬퍼 함수)
  ↓
View (입출력)
  ↓
Service (조율)
  ↓
Application (실행)
```

### 각 단계의 완성 기준
- ✅ 테스트 코드 작성 완료
- ✅ 테스트 통과
- ✅ 커밋 완료
