# java-racingcar-precourse (프리코스 2주차)

## ⚙️ 자동차 경주 게임 기능 목록

1. **입출력 기능**
    - 사용자로부터 경주할 자동차 이름을 입력받음 (`,` 기준으로 구분)
    - 이동 시도 횟수를 입력받음
    - **커밋 단위:** `feat(io): 사용자 입력 기능 구현`

2. **입력 값 검증**
    - 자동차 이름이 5자 초과인 경우 `IllegalArgumentException` 발생
    - 이름이 비어 있거나 중복된 경우 예외 발생
    - 이동 횟수가 0 이하이거나 숫자가 아닐 경우 예외 발생
    - 예외 발생 시 애플리케이션 종료
    - **커밋 단위:** `feat(validation): 입력값 검증 기능 구현`

3. **자동차 전진 로직**
    - 0~9 사이의 무작위 값을 구함
    - 무작위 값이 4 이상일 경우 자동차가 한 칸 전진
    - **커밋 단위:** `feat(movement): 자동차 전진 조건 구현`

4. **자동차 상태 출력**
    - 각 시도마다 자동차의 이름과 이동 상태(`-`로 표시) 출력
    - 예:
      ```
      pobi : --
      woni : ---
      jun : -
      ```
    - **커밋 단위:** `feat(printStatus): 자동차 이동 상태 출력 기능 구현`

5. **우승자 판별**
    - 모든 시도 후 가장 많이 전진한 자동차를 우승자로 선정
    - 공동 우승일 경우 쉼표(`,`)로 구분하여 출력
    - 예:
      ```
      최종 우승자 : pobi, jun
      ```
    - **커밋 단위:** `feat(winner): 우승자 판별 기능 구현`

6. **예외 처리 통합**
    - 잘못된 입력 발생 시 `IllegalArgumentException` 발생 후 종료
    - 예외 발생 시 사용자에게 안내 메시지를 출력하지 않고 프로그램 종료
    - **커밋 단위:** `feat(exception): 예외 처리 로직 통합`

7. **전체 게임 진행 및 통합 테스트**
    - 게임의 전체 흐름을 순서대로 실행
        1. 이름 입력
        2. 횟수 입력
        3. 각 시도별 전진 결과 출력
        4. 최종 우승자 출력
    - JUnit5, AssertJ를 사용하여 주요 기능 테스트 작성
    - **커밋 단위:** `test(game): 전체 게임 통합 테스트 작성`
